# 测试与质量规范

## 最低质量门槛

每次功能变更至少满足：

1. 受影响的 macOS target 能成功 Build。
2. 新增或变更的领域规则具有单元测试，或在日志说明无法自动测试的原因。
3. 手工检查浅色、深色、空数据和包含数据的状态。
4. 不得破坏 Today、任务、课程和日历的已有数据联动。

## 关键自动化测试

- CourseSession 在正确星期与学期范围内生成。
- Today 聚合按时间排序，且不重复显示数据。
- Assignment 与关联 Task 的创建和完成同步。
- Task 的 Today / Upcoming / Completed 筛选正确。
- JournalEntry 同一自然日不会重复创建。
- DailyLifeOverview 能按同一自然日正确汇集日记、HabitRecord、任务和日程，且不会生成重复持久化数据。
- Habit 轨迹能将不同时间的 HabitRecord 归一到本地自然日；月度 / 年度完成次数、当前连续与最长连续统计正确，重复旧记录不重复计数。

## 手工回归清单

- 创建课程与每周课次，确认它出现在 Today 与 Calendar。
- 创建作业，确认关联任务与 Deadline 均正确。
- 创建带时间和仅 Deadline 的任务，确认展示位置正确。
- 创建考试与普通日程，确认日历与 Today 聚合正确。
- 在日历“今日习惯”中打开一项“完成轨迹”，确认已完成日期染色；对过去日期补记／撤销后，月日历、日记和 Today 的 Habit 状态同步更新，未来日期不可修改。
- 完成任务，确认 Today 完成度更新。
- 重启应用，确认关键数据仍存在。
- 打开应用并进入“设置 → 自动数据保护”，确认当天快照已出现；执行人工测试数据导入或恢复后，确认列表新增对应的导入前／恢复前保护点且可恢复。
- 检查中文文案、键盘操作、深浅色模式和窗口尺寸变化。

## 失败处理

- 不忽略编译警告中与并发、SwiftData 关系或数据丢失有关的问题。
- 测试或构建失败时，优先修复或回退当前小改动，不叠加新功能。
- 将已知限制、失败原因和下一步写入当天开发日志。
