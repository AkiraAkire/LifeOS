# macOS UI / UX 设计规范

> 更新至 2026-08-30：本规范的视觉基线为「Warm Minimal Life OS」。有关导航范围、数据保护与近期功能语义，以 `01-product-requirements.md`、`05-data-model.md` 和 D-025 至 D-053 为准；下列令牌适用于后续所有页面改造。

## Warm Minimal Life OS 视觉基线

- 以语义化画布、侧边栏和内容表面构成基础层次：浅色外观偏暖白／暖灰，深色外观偏深炭灰；避免纯白大面积与冷灰 SaaS 风格。
- 品牌强调色使用低饱和鼠尾草绿；选择状态、链接和完成状态仅以低透明度强调，禁止使用高饱和整块蓝色。
- 页面标题使用 28pt semibold，日期等叙事信息可使用 24pt；正文 15pt，辅助信息 13pt。
- 全局间距只使用 4、8、12、16、20、24、32、40、48pt；圆角优先使用 8、12、16、20pt。
- 卡片仅在用于分组、编辑或承载操作时出现；使用细分隔线和低对比边框，不使用厚描边、强阴影或大面积渐变。
- 类型色低饱和且具有语义：课程蓝灰、任务鼠尾草、日记暖杏、日历雾蓝、截止日期陶土色。颜色不能作为唯一状态提示。
- 悬停与选中仅使用 150–250ms 的 `easeInOut` 过渡，避免抢占注意力的弹跳和位移。

## 设计方向

LifeOS 应接近 Apple Calendar、Reminders、Notes 与 Finder 的原生体验：清晰、克制、信息层级稳定。不得设计成网页 Dashboard、SaaS 后台或游戏化界面。

## 布局

- 根容器采用 `NavigationSplitView`：左侧 Sidebar，中间主内容区。
- Sidebar 顺序：今天、日历、任务、课表、课程、日记；底部为设置。
- Sidebar 的“今天”行以独立主按钮进入 Today；行末下拉菜单用于选择天气，避免天气菜单吞掉页面跳转点击。
- 天气图标统一使用语义色：晴天暖橙、阴天中性灰、雨天蓝色；侧边栏、日记列表与天气选择器保持一致。
- 新建入口归属到对应模块，避免在所有页面显示全局“＋”；当前任务、课程、日记各自维护创建操作。
- Sidebar 使用自定义低对比选中胶囊、极轻悬停层和语义化图标，不使用高饱和蓝色背景作为常规选中态。
- Today 使用日期头部、当前学期周次、时间轴、任务与 Deadline 分区；保持充足留白。当前日期不在学期范围时显示“当前不在学期内”。
- 根导航栏负责显示当前模块名称；内容区不得再次展示相同的模块名。页面头部只保留日期、当前筛选范围、课程名称或说明等独有信息。
- Today 顶部不重复展示课程、任务、日程和完成度概览卡；具体信息由下方时间轴与任务分区承担。课程列表行只显示课程名称，详细资料留在右侧详情中。
- 周日历采用顶部对齐的七日卡片列：中文星期、日期、今日状态和来源图标帮助快速扫读；课程、日程、任务、考试分别使用课程色、橙色、紫色和红色。
- 月日历是生活地图：日期格只展示日记标记、当天已完成 Habit 的 SF Symbol、Habit 完成环和任务完成比；不得显示课程、日程或任务的标题、描述与“+N”。具体安排仅在点击日期后的当天生活检查器中呈现。日期格的整个矩形区域均为日期选择命中区。
- 月日历固定采用连续六行网格，并显示相邻月份的日期，避免首周出现大块空白或日期丢失；格高应由实际可视高度计算。任务完成比必须使用不可换行的紧凑数字形式（例如“1/3”）。
- 月视图在正常内容宽度显示左侧常驻迷你月历：可前后切换月份并点按任意日期；它必须与主月历标题、选中状态和当天生活检查器共用同一日期状态。内容宽度不足时隐藏该辅助导航而不压缩主月格或制造横向溢出。
- 点击日期后，右侧“当天生活”检查器展示日记、安排、任务与 Habit；“查看日记 / 写日记”直接定位到该日期，日记右侧摘要可返回对应日期的日历。
- 日历详情在内容区宽度充足时作为右侧检查器显示；空间不足时必须收起为“当天生活”按钮并以原生 Sheet 打开，禁止挤压月格、裁切工具栏或强制页面横向溢出。
- 日历页以明确的“新建日程”按钮创建个人日程，不使用无语义的全局加号；表单至少提供标题、日期、全天／起止时间、地点与备注。
- 日历“今日习惯”区提供“管理”按钮：已展示的 Habit 以图标、名称和明确的“移除”操作呈现，避免用开关混淆“展示选择”和“完成状态”；用户仍可从常用习惯中重新添加或创建自定义 Habit。日记的今日生活摘要必须读取同一份展示选择。
- 日历“今日习惯”的名称区域可进入“完成轨迹”：使用原生 Sheet 展示单个 Habit 的月度完成日历与全年缩略图；完成日使用低饱和强调色和勾选表示。仅当天及过去日期可在月历中点按补记或撤销，历史操作必须直接复用同一 HabitRecord，并立即同步到日历、日记和 Today。
- 课表在 100% 默认缩放下应完整容纳全部已配置节次；课程卡片允许完整换行，不以省略号隐藏名称、时间、周次或教室。相同时段的课程使用并列轨道，特别是在“全部”周次模式下将单双周课程分栏显示。
- 课表进入时按当前学期周次默认选择“单周”或“双周”；工具栏提供“学期设置”，以独立 Sheet 设置开始日期、结束日期和 1–52 周的学期总周数。开始日期所在的自然周为第 1 周，此后每周星期一换周；修改总周数时结束日期自动对齐到最后一周的星期日。
- 课程日期覆盖入口位于“课程”页面的课程编辑 Sheet，以及新增／编辑课程时间的 Sheet；关闭“跟随课表学期日期”即可编辑该课程独立日期，必须以辅助文字解释其不影响其他课程。
- 详情编辑优先使用 Sheet 或 Inspector，不用网页式弹窗堆叠。
- 课程页面首次进入时使用自适应的知识卡片网格，用户先选择要学习或维护的课程；卡片突出课程图标、名称、最近课次及已有作业／考试状态，避免在首屏堆叠资料表单。
- 课程图标优先提供低认知成本的 SF Symbol 预设；允许输入最多四个字符／Emoji 或选择本机图片作为自定义图标。图标和课程色仅强化辨识，名称始终保留为主要信息。
- 选中课程后进入全宽详情工作区；详情从内容区左缘开始并铺满可用宽度，返回操作回到课程卡片首页，避免嵌套多栏产生过大空白或约束循环。
- 日记在宽窗口使用可拖拽的三栏 `HSplitView`；空间不足时保留历史栏与编辑栏，将“今日生活”摘要收起为原生 Sheet 入口，不为单页设置强制横向滚动宽度。
- 日记以“生活回顾”呈现：正文列最大宽度约 740pt，空白日仅显示轻量开始记录状态；右侧摘要提供当天 Habit 勾选、任务回顾和日历跳转，正文下方以只读足迹回顾当天安排。
- 日记历史栏顶部使用常驻迷你月历查找日期：箭头仅切换浏览月份，点按日期才切换编辑目标；已有日记用暖杏色圆点标记。选择空白日不得自动写入 `JournalEntry`，仍由用户开始记录并保存时创建。

## 视觉规则

- 优先使用系统字体、动态字号、SF Symbols 和语义色。
- 支持浅色、深色与“跟随系统”。
- 不滥用渐变、重阴影、厚边框或高饱和卡片。
- 课程、日程、任务用图标、色点和简短中文标签区分；不要仅依赖颜色传达信息。
- 信息密度以可扫读为先：标题、时间、状态是首要层级；描述为次要层级。
- 任务行在 Today 显示当天具体安排时间；在任务列表显示中文“安排 / 计划 / 截止”日期，避免将截止日期误读为计划日期。
- 任务行右键菜单与任务详情的“今日任务”区都提供“设为今日任务 / 移出今日任务”；两处操作必须复用 Today 拖放的安排规则，且设为今日时清除旧的具体安排时间。

## 中文文案

- 使用简体中文和清晰动词，例如“新建任务”“标记为完成”“添加课程时间”。
- 时间使用本地化格式；界面不出现未经翻译的英文功能名。
- 空状态要解释当前状态并提供归属明确的下一步，例如“今天还没有安排。可前往任务页安排任务，或在日历中新建日程。”
- 危险操作需明确中文确认，例如“删除后无法恢复，确定要删除这门课程吗？”

## 可访问性

- 所有图标按钮必须提供 `accessibilityLabel`。
- 不以颜色作为唯一状态提示；完成、优先级、来源应有图标或文字。
- 保证键盘操作可达：列表选择、创建、保存、取消和删除均应具备快捷键或标准菜单支持。
