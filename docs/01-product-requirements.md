# LifeOS 当前产品需求

> 更新至 2026-08-30。本文件描述已实现的本地优先产品基线；后续功能不得以本文件为由提前引入账户、云同步或 AI 服务。

## 产品定位

LifeOS 是运行在 macOS 上、界面全部使用简体中文的个人生活管理应用。它以“今天”为第一入口，把课表、课程、日程、任务、日记与习惯记录组织到同一条时间脉络中：过去由日记与习惯回顾承载，今天由 Today 与当天生活承载，未来由课表、日历与截止日期承载。

产品坚持本地优先：无需登录、无需服务器，用户数据保存在本机 SwiftData 存储中，并由自动保护和可移植备份保护。

## 当前导航与核心闭环

侧边栏仅保留以下主入口：

| 页面 | 用户要完成的事 | 与其他页面的联动 |
| --- | --- | --- |
| 今天 | 查看教学周、当天时间轴、今日任务与按截止日期排序的任务列表；接收拖入或从任务页设为今日的任务 | 读取课程、日程、考试与任务；天气读取今日日记 |
| 日历 | 按月、周、日回顾生活；创建个人日程；查看当天生活与单项习惯轨迹 | 同时汇集课程、日程、考试、任务、日记和 HabitRecord |
| 任务 | 在“今天／全部／已完成”中创建、编辑、完成和删除任务，并可设为今日任务 | 截止日期驱动任务列表；设为今日或拖放至 Today 写入当天安排 |
| 课表 | 查看本周课程、单双周和跨节课程；配置节次与学期 | 直接读取 CourseSession，日期范围影响课程展示 |
| 课程 | 从知识卡片首页选择课程，维护课程资料、课程时间、作业和考试 | 课程时间进入课表、Today 与日历；作业关联任务；考试进入日历 |
| 日记 | 按自然日记录心情、天气、每日一句和正文，并回顾当天足迹 | 与日历共享当天生活、展示习惯选择和 HabitRecord |
| 设置 | 配置启动页、外观和时间偏好；管理自动保护与完整备份 | 偏好保存在本机；备份覆盖全部本地生活数据与展示偏好 |

### 每日使用路径

1. 打开应用进入 Today，确认天气、当前教学周、课程和已安排任务。
2. 将需要今天执行的任务拖入“今日任务”，或在任务页面直接设为今日任务；仅提供截止日期的任务留在任务列表中等待安排。
3. 在课表或课程页维护学期课程、单双周与作业／考试；在日历创建个人日程。
4. 在日记记录当天心情、天气和正文；日记可回顾当天已完成的习惯、任务与安排。
5. 自动保护会在启动及应用转为非活动状态时更新；需要迁移或长期存档时再导出 `.lifeosbackup`。

## 已实现功能范围

### Today

- 显示本地日期、当前教学周或“不在学期内”提示。
- 以统一时间轴聚合课程、个人日程、考试和带具体时间的任务。
- 今日任务由 `plannedDate` 标记；拖入 Today 或从任务页面设为今日任务都会清除旧的具体安排时间，避免日期语义冲突。
- 任务列表按截止日期呈现，完成状态与任务页共享同一 `Task`。
- 侧边栏天气快捷入口只更新当天唯一日记的天气字段。

### 任务

- 新建任务时以标题和可选截止日期为核心；描述、优先级、课程关联与可选的具体安排时间仍可编辑。
- 页面范围为“今天、全部、已完成”；历史 `inbox` 状态任务保留在数据中并显示于“全部”，但不再提供收集箱入口。
- 在任务行右键菜单和任务详情的“今日任务”区均可直接设为今日任务或移出今日任务。
- 截止日期、计划日期和具体安排时间的展示使用明确中文标签，防止把截止日误认为执行日。

### 课表与课程

- 课表支持可编辑节次、跨节课程块、72%–180% 双指捏合缩放、单双周筛选与“全部”周次并列轨道。
- 全局学期设置以开始日期所在自然周作为第 1 周，之后每周星期一换周；可设置 1–52 周，结束日期自动对齐至最后一周星期日。
- 课程默认继承全局学期日期；可关闭“跟随课表学期日期”，单独覆盖该课程的起止日期而不影响其他课程。
- 每门课程可维护课程资料、每周课次、作业与考试；课程时间按周一至周日、同日按起止时间稳定排序。
- 课程页首先显示可自适应的知识卡片，用户从中选择想学习或维护的科目；每门课程可选择预设 SF Symbol，或输入短文字／Emoji 作为自定义图标，并随完整备份保留。

### 日历、日记与习惯

- 日历提供月、周、日视图、“新建日程”表单，以及月视图内可直接跳转任意日期的迷你月历导航。
- 月视图是生活状态地图：日期格只显示日记标记、完成习惯符号／完成比与任务完成比；安排详情在“当天生活”检查器或 Sheet 中显示。
- 日历可管理在日历／日记中展示的习惯；“移除”只隐藏展示，不删除 Habit 或历史记录。也可创建自定义习惯。
- 点按某个展示习惯可打开完成轨迹：月度可补记／撤销（仅今天及过去日期）、全年缩略图、完成次数、当前连续和最长连续。
- 日记按自然日唯一、自动保存；历史条目通过右键删除。日记支持心情、晴／阴／雨天气、每日一句、正文和重要事件。
- 日记历史栏提供迷你月历日期导航：可前后浏览月份、以圆点标记已有日记，并直接选择任意日期开始回顾或记录。

### 数据保护与人工测试

- 设置页支持完整 `.lifeosbackup` 导出、校验预览和破坏性恢复确认。
- 自动保护保存在应用私有目录：最近 7 份日快照、较早 4 份周快照，以及最多 14 份导入前／恢复前保护点。
- “导入人工测试数据”会在确认后替换本机数据；导入前自动创建保护点。

## 当前明确不做

- 登录、账户、服务器、iCloud／CloudKit、跨设备同步或第三方日历同步。
- AI 助手、自然语言快速添加、AI 日计划、周回顾与 Ask My Life。
- 可见的项目、统计和独立习惯管理页面；`Project`、`Habit` 与相关历史模型暂为兼容、备份和日历／日记联动保留。
- 真实通知调度；设置中通知控件当前仅为后续版本占位。
- 调课、停课、补课等单次课程例外规则。

## 不变产品规则

- 所有 UI 文案、菜单、空状态和错误提示使用简体中文；代码符号与数据字段使用英文。
- 同一事实只保存一份：课程不复制为日程，Today、Calendar、Journal 通过 Service 动态聚合。
- “某一天”统一以当前用户日历的本地自然日计算，不以格式化字符串比较日期。
- 破坏性数据操作必须显示中文确认，并在执行前创建可恢复的保护点（适用时）。
