# LifeOS V1 开发需求

## 产品定位

LifeOS 是一个运行于 macOS 的简体中文个人生活管理系统。它以“今天”为第一入口，把课程、日程、任务、截止日期与日记连接为统一的个人生活 Dashboard。

## V1 成功标准

用户能够在本地完成以下闭环：

1. 添加课程、课程时间、作业、考试、任务和日程。
2. 在 Today 查看当天课程、日程、带时间任务、待完成任务和近期截止日期。
3. 在日历查看课程、日程、考试和带时间任务。
4. 在任务中管理收集箱、今天、即将到来和已完成事项。
5. 记录当天心情、每日一句和日记正文。

## V1 模块边界

| 模块 | V1 必须实现 | V1 不实现 |
| --- | --- | --- |
| 今天 | 日期、概览、统一时间轴、任务、Deadline、快速日记入口 | AI 规划、习惯卡片、统计图表 |
| 日历 | 月、周、日；课程 / 日程 / 考试 / 任务聚合显示；月视图的日记、Habit 与任务完成状态；单项 Habit 的月度 / 年度完成轨迹 | 外部日历同步 |
| 任务 | 收集箱、创建编辑、优先级、计划日期、截止日期、完成状态 | 智能排序、批量自动整理 |
| 课程 | 课程、每周课次、作业、考试、备注 | 云端课表导入 |
| 日记 | 心情、天气、每日一句、正文、历史记录；当天足迹与 Habit / 任务回顾 | AI 日报草稿 |
| 设置 | 通用、外观、通知及数据项的基础界面 | 真实云同步、AI 服务接入 |

## 延后版本

- V2：Habit、Project UI、Statistics、Inbox 独立管理、Life Calendar、独立 Timeline。
- V3：自然语言快速添加、AI 日计划、周回顾、Ask My Life、智能提醒与云同步。

## 不变的产品规则

- 所有用户界面文字均为简体中文。
- 完全本地运行，无账户、服务器或登录流程。
- 同一项数据不得在多个模块复制保存；不同页面只展示同一数据源的不同聚合视图。
- 今天优先于模块优先：用户启动后默认进入 Today。
