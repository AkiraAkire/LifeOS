# 人工测试原始数据集

数据文件：`../LifeOS/Resources/manual-test-dataset.json`

## 用途

该文件根据用户提供的课表截图整理，并补充了任务、作业、考试、日程与日记数据。它用于手动录入测试，也可在“设置 → 导入人工测试数据”中经明确确认后导入；应用不会自动读取或导入它。

## 固定测试基准

- 时区：`Asia/Shanghai`
- 基准日：2026 年 8 月 26 日（星期三）
- 学期范围：2026 年 8 月 24 日至 12 月 31 日

测试任务分组时，请将系统日期或模拟数据日期设为基准日。数据集包含 10 门课程、14 条课次、3 项作业、2 场考试、10 项任务、2 项日程、3 项习惯和 3 篇日记。它保留一条历史 `inbox` 状态任务以验证旧数据兼容；当前任务页面不再显示“收集箱”入口，该任务应在“全部”中可见。

## 录入顺序

1. 在“课表 → 节次设置”中录入 `timetablePeriods`，并在“学期设置”中录入学期范围。
2. 新建 `courses`，再按 `courseSessions` 添加课程时间。`weekday` 使用 Apple `Calendar` 规则：1 为周日、2 为周一，依此类推。
3. 录入作业、考试、任务和日程；`courseID` 是 JSON 内部关联标识，手工录入时选择对应课程即可。任务只需提供截止日期；如需验证 Today 拖放，可先保持任务未安排。
4. 在日记页面按 `journalEntries` 创建或填写历史记录；在日历“管理今日习惯”中选择导入的习惯以验证共享展示和完成轨迹。

## 截图转写说明

截图中部分教师、教室和班级编号的文字难以完全辨识。已确认的单双周信息写入 `courseSessions.weekPattern`：工程电路与电子基础为单周，材料化学为双周。周二第 3–4 节仍保留两门课程，用于检查单双周筛选及课表标识。

## 建议验证项

- 周三应显示“材料学综合实验”第 1–8 节，以及晚间课程。
- Today 应聚合课程、组会和三项有具体时间的任务，并显示第 1 周。
- Tasks 的“全部”应显示历史 inbox、逾期、已安排和仅截止日期任务；将一项任务拖入 Today 后应进入“今天”。
- 作业 Deadline、考试和普通日程应出现在日历；月格只显示日记、习惯与任务完成状态，不显示具体任务名称。
- 日记历史列表应展示三条不同心情／天气记录；日历和日记都应可查看导入习惯的完成状态。
