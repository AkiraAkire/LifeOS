# 人工测试原始数据集

数据文件：`../LifeOS/Resources/manual-test-dataset.json`

## 用途

该文件根据用户提供的课表截图整理，并补充了任务、作业、考试、日程与日记数据。它用于手动录入测试，也可在“设置 → 导入人工测试数据”中经明确确认后导入；应用不会自动读取或导入它。

## 固定测试基准

- 时区：`Asia/Shanghai`
- 基准日：2026 年 8 月 26 日（星期三）
- 学期范围：2026 年 8 月 24 日至 12 月 31 日

测试任务分组时，请将系统日期或模拟数据日期设为基准日。数据集中涵盖：收集箱、今天的上午 / 下午 / 晚上、逾期、明天、本周、下周、更晚和已完成任务。

## 录入顺序

1. 在“课程 → 课表 → 节次设置”中录入 `timetablePeriods`。
2. 新建 `courses`，再按 `courseSessions` 添加课程时间。`weekday` 使用 Apple `Calendar` 规则：1 为周日、2 为周一，依此类推。
3. 录入作业、考试、任务和日程；`courseID` 是 JSON 内部关联标识，手工录入时选择对应课程即可。
4. 在日记页面按 `journalEntries` 创建或填写历史记录。

## 截图转写说明

截图中部分教师、教室和班级编号的文字难以完全辨识。已确认的单双周信息写入 `courseSessions.weekPattern`：工程电路与电子基础为单周，材料化学为双周。周二第 3–4 节仍保留两门课程，用于检查单双周筛选及课表标识。

## 建议验证项

- 周三应显示“材料学综合实验”第 1–8 节，以及晚间课程。
- Today 应聚合课程、组会和三项有时间的任务。
- Tasks 的“今天”应出现上午、下午、晚上分组；“即将到来”应出现逾期、明天等分组。
- 作业 Deadline、考试和普通日程应出现在日历。
- 日记历史列表应展示三条不同心情的记录。
