# V1 实施步骤与验收标准

## 开发纪律

一次只推进一个相对独立、可验证的阶段。每个阶段完成前必须成功编译；未解决的失败不得被下一个阶段掩盖。

## 阶段 0：工程基线

产出：Xcode macOS SwiftUI 工程、SwiftData ModelContainer、目录骨架、Sidebar 导航与文档 / 日志机制。

验收：空工程能运行，Sidebar 可切换占位页面，默认进入“今天”。

## 阶段 1：核心数据模型

产出：Task、Event、Course、CourseSession、Assignment、Exam、JournalEntry、Tag 及枚举；测试性预览数据。

验收：ModelContainer 能创建和保存各实体；关键关系可正确建立与删除。

## 阶段 2：Today

产出：日期头部、今日概览、统一时间轴、任务与 Deadline 区域。

验收：课程、日程、考试、带时间任务能按时间正确汇聚；完成任务后概览同步变化。

## 阶段 3：Tasks

产出：收集箱、今天、即将到来、已完成列表及任务编辑界面。

验收：任务创建、编辑、完成、截止日期和筛选都能持久化；Today 数据同步。

## 阶段 4：Courses

产出：课程列表、课程详情、每周课次、作业、考试与课程备注。

验收：课次进入 Today / Calendar；作业关联 Task；考试进入 Today / Calendar。

## 阶段 5：Calendar

产出：月、周、日视图与统一的日历条目展示；月视图显示只读的日记、Habit 与任务完成状态，并可进入所选日期的日记。

验收：Event、CourseSession、Exam、带时间 Task 均显示正确，日期切换无遗漏或重复。

## 阶段 6：Journal

产出：每日心情、每日一句、正文、历史记录，以及当天足迹、Habit 与任务的回顾摘要。

验收：同一天重复进入仍编辑同一条记录；历史记录可按日期读取。

## 阶段 7：Settings 与稳定性

产出：通用、外观、通知、数据设置的基础界面；空状态、错误提示与收尾测试。

验收：主题可切换、设置可持久化、核心闭环通过手工回归。

## 每阶段交付格式

完成阶段时记录：新增文件、修改文件、实现内容、构建 / 测试结果、已知限制、下一步待办。
